# 🧠 SQL Builder UI

An interactive SQL Builder UI built using **React + TypeScript** that helps users explore and generate SQL queries visually. It supports:

- ✅ DDL (Create, Alter, Drop)
- ✅ DML (Insert, Update, Delete)
- ✅ DCL & TCL (Grant, Commit, etc.)
- ✅ Joins (Inner, Left, Right, Full)
- ✅ Subqueries
- ✅ Aggregate Functions (SUM, COUNT, etc.)
- ✅ String / Date / Time Functions
- ✅ Set Operations (UNION, INTERSECT, etc.)
- ✅ Common Table Expressions (CTEs)
- ✅ Schema Visualizer
- ✅ Query Editor & Saved Queries
